# Linux and Git Command Cheat Sheet

## Linux Commands

### pwd

Displays the current working directory.

### ls

Lists files and directories in the current location.

### cd

Changes the current working directory.

### mkdir

Creates a new directory.

### rm

Removes files or directories.

### cp

Copies files or directories from one location to another.

### mv

Moves or renames files and directories.

### cat

Displays the contents of a file.

### grep

Searches for specific text patterns within files.

### chmod

Changes file and directory permissions.

## Git Commands

### git init

Creates a new Git repository.

### git status

Displays the current status of the repository.

### git add

Stages changes to be included in the next commit.

### git commit

Saves staged changes to the repository history.

### git branch

Creates, lists, or manages branches.

### git checkout

Switches between branches or restores files.

### git merge

Combines changes from one branch into another.
